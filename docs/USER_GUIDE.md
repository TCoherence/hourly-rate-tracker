# 使用与计算说明

本机 Mac 工具：按指定 VPN 的连接状态计时，每 **15 秒**采样、每 **1 分钟**把待同步记录发布到**同一台 Mac**的仪表盘。提供理论时薪、实际时薪、每日工时与时薪折线图、热力图和时间范围筛选。

**没有云端上传。** 可通过系统 VPN 或自己提供的本机状态脚本读取状态；采集默认关闭。只有明确的连接和断开状态才分别记为已连接和已断开，无法确认的情况记为未知。项目本身不会连接、断开或重连 VPN。

## 启动与停止

只想看界面时，可以直接打开同目录 **preview.html**：这是可切换周期的只读离线演示，内嵌的全部是模拟数据，不能开启采集或保存设置。

需要 Python 3.10 或更新版本；所有运行依赖均为 Python 标准库，无需 pip 或 npm 安装。

1. 双击同目录的 **start-hourly-rate.command**。首次打开默认没有工资、没有真实记录。
2. 点 **演示预览** 查看独立模拟数据；示例年薪 180,000 不会写入你的真实设置。
3. 点 **设置** 填写初始年薪、币种和每日理论工时（默认 8 小时）；发生调薪时添加 **生效日期 + 年薪**。历史记录按对应日期的薪资重新计算。
4. 关闭浏览器不影响后台运行。双击 **stop-hourly-rate.command** 结束采集。

默认不会安装登录启动项，可在设置中选择启用；未启用时 Mac 重启后需再次打开启动文件。不要为此工具绕过公司限制或关闭系统保护。

熄屏或锁屏本身不会暂停后台计时：Mac 仍保持唤醒且 VPN 已连接时，按夜间等设置决定是否累计。设置中的 **睡眠期间暂停计时** 默认开启；开启时通过 macOS 睡眠/唤醒事件排除睡眠时间，唤醒后自动恢复 VPN 检测。

关闭此开关时，只有收到完整睡眠与唤醒事件，且睡前 45 秒内最后确认 VPN 已连接，才会在唤醒后补入“睡眠估算”工时；它不代表睡眠期间实际检测到 VPN 连接。设置切换会重算已经记录的睡眠区间，手动补录优先且不受开关影响。旧采样缺口、未配对事件和应用停止时间不会补成睡眠工时；升级不会覆盖用户已明确保存的开关选择。

**夜间自动暂停计时**可在设置中开启并调整时间，预填 00:00–09:00，支持跨午夜；新安装默认关闭。启用后，时段内自动连接记录（包括睡眠估算）不计入工时，结束后自动恢复计入；只改变统计，不关闭或重连 VPN。修改规则会重算历史，原始观测保留；手动补充、总小时和修正优先，可以把确实工作的夜间时段加回来。

首页的 **暂停计时 / 恢复计时** 按钮适合临时结束工作。手动暂停后仍会检测并保存 VPN 状态，但该时段不计入自动工时；即使重启应用也会保持暂停，直到主动恢复。恢复后如仍处于夜间暂停时段，要等夜间规则结束才会继续计入。工作历史可手动补充或修正暂停时段；原始 VPN 状态始终保留。

睡眠识别状态显示在设置中；不可用时保留普通 VPN 检测，未确认缺口按未知处理。工具不会修改电源设置或阻止睡眠。停止后台后需重新启动应用；启用登录后自动启动时，注销或重启后需登录 macOS 才会自动运行。

启动器会复用已有服务；同时双击也只启动一个实例。服务以数据目录为单位加系统锁，即使改端口也不能共用一个目录启动多个实例。重复启动或端口冲突失败发生在打开 SQLite 之前，不会新增状态记录或发布数据。两个 `.command` 文件会自动选择 Python 3.10+，优先使用已安装的 Python 3.12。

设置中的「登录后自动启动」会在本用户的 `~/Library/LaunchAgents` 安装配置，下次登录 macOS 时启动后台服务，不打开浏览器。服务沿用开启时的项目路径、数据目录与端口；移动或删除项目后请重新配置。系统设置也可能禁用此登录项，页面会显示检测到的状态；无法确认时显示状态未知。关闭选项不会停止当前运行的服务。本机状态脚本路径保存在应用设置中；若移动或删除脚本，需要更新设置。

开发运行：

```sh
python3 app.py --port 8765
```

手工运行后，用同目录 `python3 launcher.py` 在系统默认浏览器打开带本机访问凭据的页面。首次打开后，应用在浏览器本地保存一份 14 天的授权凭据；期间服务重启后同一浏览器可自动恢复，正在显示的页面也会在服务恢复后重新读取。

授权保存在具体浏览器配置和地址中，换浏览器、换端口、无痕模式或清除浏览器数据后需通过启动入口重新授权；浏览器若不保留站点数据则可能更早失效。需要在其他系统浏览器打开时，可在项目目录运行例如 `python3 launcher.py --browser-app "Google Chrome"`，将名称替换为本机浏览器的应用名称。不同浏览器分别授权，请不要分享启动链接。

在设置中的「浏览器授权」可以查看并延长当前浏览器授权：操作时起至少保留 14 天，不会缩短尚未到期的授权，也不会重启服务或影响计时。其他浏览器要分别在各自页面操作；已过期、被撤销或已清除的授权需要重新通过本机入口打开。有效期到后不会在普通页面刷新时静默续期；设置中也可以撤销全部浏览器授权。短期会话可持续到当前服务重启，每次写操作仍有独立请求验证。持久凭据保存在浏览器的同源本地存储，服务端仅在本机私有文件中保存验证信息，不包含在 SQLite/JSON 导出中。

启动器也支持 `--port`、`--data-dir` 和 `--no-browser`；自定义数据目录时，停止命令须带相同的 `--data-dir`。启动器从该目录读取实际端口并复用或停止已有服务。默认双击启动/停止文件使用默认数据目录，首次启动端口为 8765。

顶部的外观选项支持 **跟随系统 / 浅色 / 深色**，默认跟随系统。选择保存在当前浏览器，与薪资和计时设置独立，不会重算或清空工时。

时间筛选栏旁的“隐藏数字”用于隐藏薪资、时薪、金额和百分比；“隐藏时间”用于隐藏工时和具体时段。两个开关可独立使用，相应的具体数值以 `***` 代替。日期、趋势曲线及热力图与工作历史日历的色块保留，因此仍能看出相对变化。工作历史保留日期导航和色块，隐私模式下不可直接编辑敏感内容；未保存的草稿会保留。设置中的薪资和时间配置也会按对应开关隐藏，恢复显示后即可查看和编辑。偏好保存在当前浏览器，也会同步到该浏览器的其他标签页。

该功能用于减少屏幕旁观，并不加密或删除本机数据；SQLite、JSON、CSV 导出仍包含真实数据，分享文件或屏幕前请自行确认。

## 熄屏提醒

设置中的 **熄屏过久时提醒确认** 默认开启，连续时长默认 **4 小时**，可在 1–24 小时之间调整。只有采样确认所有在线显示器都处于休眠、VPN 已连接且该时段正在自动计入工时，才开始累计提醒时长；夜间暂停、手动暂停、整机睡眠或无法确认的状态会中断这一时段。

达到阈值后，首页显示待确认时段，供你去工作历史查看、修正或排除，也可以稍后处理。确认完成仅收起提醒，不修改工时；正在自动记录的时段仍受工作历史的编辑保护。屏幕休眠并不代表一定没有工作，原始 VPN 记录始终保留。

显示器状态随后台采样约每 15 秒检查一次，采样点之间的短暂亮屏可能被漏过，提醒只是一条线索。当前多屏、镜像和合盖场景尚未实机验证；无在线显示器或读取失败时按未知处理。程序停止期间及开始检测之前的屏幕状态无法回溯，重启后从新的确认样本开始，不把缺口拼成连续熄屏。应用只读取显示器是否休眠，不读取屏幕内容或键盘输入。

首页计时卡片上的小驴使用矢量动效；当系统设置要求减少动态效果时，动画停止。

## 按时间设置薪资

新安装会尝试识别系统 IANA 时区，无法识别时回退 UTC；已有数据库保留已保存的时区。设置中可查看和修改，修改后历史记录会按新的本地日期重新划分。

- **初始年薪**适用于第一条生效日期之前；没有变更记录时适用于全部历史。旧版本保存的年薪自动作为初始年薪保留。
- 每条变更填生效日期和新的固定年薪，从设置时区的当天零点起生效，直到下一条变更。可以新增、编辑、删除，也可提前录入未来调薪；未来变更不会影响今天或过去。
- 例如初始年薪 180,000，2026-07-01 起 210,000：上半年按 180,000，下半年按 210,000 的年度标准分摊。保存后重新计算，原始 VPN 记录不变。
- 初始年薪可以留空。如果选定统计范围内有记录的理论工作日缺少对应薪资，实际时薪暂不显示，并提示补齐薪资；不会把未知薪资当成零。
- 全部薪资使用同一币种，没有自动汇率换算。理论工作日和每日理论工时仍是一套全局设置；修改后重新计算，不改动原始 VPN 记录。

## 本机状态脚本

当系统 VPN 检测不适合你的客户端时，可以自行准备一个可执行的本机脚本，把特定客户端的状态转成以下通用协议：

- 程序不带参数运行脚本，退出码为 0，标准输出只能是一行 `connected`、`disconnected` 或 `unknown`。
- `connected` 计为已连接，`disconnected` 计为已断开；`unknown`、脚本缺失、无权限、非零退出、超时或其他输出均记为未知。未知时不推测工作时间。
- 在设置中选择 **本机状态脚本**，填写脚本的绝对路径，启用计时后保存。路径或来源修改后请先保存，再点击 **检查已保存的脚本状态**；该检查不会写入工时。
- 应用以当前用户身份直接运行脚本，不通过 shell 解析命令。**只配置自己信任的脚本**：脚本本身可执行任意该用户有权限的操作，应用不能保证第三方脚本只读。
- 项目只定义状态协议；针对特定客户端的个人适配脚本自行保存在本机，不需要提交到项目。连接状态不代表目标内网服务可达；如需此信息，应另外独立检测。

推荐将个人脚本保存在本机数据目录的 `adapters/` 下，避免与准备公开的项目源码放在一起。默认数据目录对应的建议路径为 `~/Library/Application Support/HourlyRateMVP/adapters/status`；使用 `--data-dir` 指定其他数据目录时，可使用该目录下的 `adapters/status`。设置页填写的是完整绝对路径；不要把路径里的 `~` 原样填入。脚本须由使用者自行准备并设置为可执行文件。

此前使用项目目录下默认适配脚本的设置，会在读取时映射到当前数据目录中的 `adapters/status`；其他自行配置的脚本路径不会被改写。旧版来源标识可通过数据目录中私有的 `adapters/legacy-compat.json` 映射到通用来源；该文件由使用者管理，不属于项目源码。读取时不会为迁移改写历史数据。脚本本身需要存在于新位置，缺失或无法执行时状态显示为未知；无法识别旧来源时不会猜测连接状态。

如果需要迁移旧配置，兼容文件的格式如下，名称仅为虚构示例：

```json
{
  "version": 1,
  "providers": {
    "old_cli": {"provider": "script", "status_script_path": "local_adapter"},
    "old_native": {"provider": "verified_system"}
  },
  "environment": {"HOURLY_RATE_OLD_CLI": "HOURLY_RATE_ADAPTER_LEGACY_PATH"}
}
```

`local_adapter` 表示当前数据目录下的 `adapters/status`；`verified_system` 使用系统 VPN 并要求完成连接和断开两态核对。环境变量值是脚本需要的绝对路径，新的通用变量优先。这个映射不随备份导出；应只为可信的旧配置建立规则，并妥善保管。

例如，下面仅用于验证接入，固定输出 `unknown`，不会产生自动工时：

```sh
#!/bin/sh
printf 'unknown\n'
```

将脚本保存到本机并授予执行权限，在设置中填入其绝对路径。实际使用时由脚本自行检查状态，不能长期使用固定输出的模拟脚本来判断工作状态。两次相邻采样形成已知时段后，可在下一次同步或点击立即同步时查看工时。

## 查看 VPN 状态日志

在设置中选择并配置状态来源，打开计时开关并保存。点击页面顶部 **实时日志**，查看最近 30 条状态变化，页面每 3 秒刷新；日志接口受同样的本机认证保护，只返回经过筛选的状态事件。也可双击 **view-logs.command** 或在终端运行：

```sh
tail -n 30 -F "$HOME/Library/Application Support/HourlyRateMVP/service.log"
```

- 第一次采样和后续状态变化会立即打印，包含本机日期、时间、时区、状态来源、统计状态及状态说明。相同结果不会每 15 秒重复刷屏。
- 可以在日常操作中手动断开/连接 VPN 对照日志；通常约 15–20 秒出现变化，不需要等待 1 分钟仪表盘同步。工具不会替你改变连接。
- 重点看 `state` 与 `message`：已确认的 `connected` / `disconnected` 分别显示连接/断开；读取失败或结果无法确认显示未知，不猜测为断开。历史日志保持原样，不改写历史。
- 若只看到 `disabled`，表示采集没有开启。点击页面“检查已保存的脚本状态”仅在页面显示结果，不写这份采集日志。
- `Control+C` 只结束日志查看，不停止采集。自定义数据目录时，请查看该目录下的 `service.log` 和 `autostart-service.log`。

## 数据传到哪里

数据流是 **只读 VPN 状态 → 本机 SQLite 待同步记录 → 每 60 秒发布本机汇总 → 本机浏览器**。

- 默认目录：`~/Library/Application Support/HourlyRateMVP/`。
- `records.sqlite3`：时间、连接/断开/未知状态、薪资和排班设置、所选系统服务标识、两态核对结果；手动补录单独存入 `manual_entries` 表，不伪造 VPN 采样。
- `adapters/`：个人自行放置的本机状态脚本，与 SQLite 数据库及项目源码分开；脚本由使用者管理。
- `access.json`：仅运行时存在的随机本机会话凭据；关闭服务后删除。
- `instance.lock` / `launcher.lock`：空的进程锁文件。退出后系统释放锁，文件保留；不要删除正在使用的锁文件。
- `service.log`：启动信息、程序异常、首次/变化的状态来源结果及系统睡眠/唤醒事件；不记录完整命令输出、节点、速率、HTTP 请求参数、薪资或访问凭据。
- `autostart-diagnostics.log` / `autostart-startup.log`：登录项启动诊断与输出，独立于手动启动日志。登录后采集的状态事件追加到 `service.log`，与手动启动共用实时日志。
- 服务只监听 `127.0.0.1`，页面和 API 需要本机会话凭据才能读取私人数据；修改还需要额外请求校验。
- 默认目录权限为 700，数据库、访问凭据和日志文件为 600。没有远程上传地址、第三方分析、云 SDK、外部字体或 CDN。
- 项目只接收状态脚本约定的连接、断开或未知结果，不保存脚本的完整输出。应用自身不读取公司网络名称、服务器地址、流量、消息、截图、代码或凭据；请自行确认第三方脚本的行为。系统 VPN 服务名称仅在你点击系统检测时于本机界面展示。

**本机保存降低外传风险，但不等于没有风险或得到公司许可。** 时间记录本身能揭示工作规律；同一系统账户、管理员及具有备份权限的工具仍可能读取文件。数据库未做额外应用层加密，操作系统加密和企业备份策略由设备管理决定。不要把数据目录放入云盘、代码仓库或外部同步目录。

## 本机导出与恢复

在“记录留在本机”区域可导出 SQLite 快照、JSON 备份或每日汇总 CSV。SQLite 和 JSON 包含薪资、设置、完整原始采样（含尚未发布的记录）、睡眠和手动修正，不包含本机会话令牌；CSV 按仪表盘已发布记录计算，不包含备注和未发布采样。导出文件保存在下载位置，请妥善保存。

SQLite 和 JSON 会保存状态脚本的路径设置，**不会包含脚本文件或本机旧版兼容映射**；CSV 也不包含它们。恢复到其他设备时，需自行准备可信脚本、确认路径并重新启用采集。含旧来源标识的备份，还需先在目标数据目录配置相应的私人兼容映射，否则会拒绝恢复；已经转换成通用来源的新备份不依赖该映射。操作系统或其他备份工具可能备份整个数据目录，处理个人文件时请按其内容和适用规则决定是否另行备份或分享。

恢复选择本应用导出的 JSON 或 SQLite 文件，核对提示并确认后才会替换本机数据；系统先在本机数据目录创建权限受限的恢复前备份，随后事务恢复。恢复后自动暂停采集、原设备 VPN 两态核对信任不迁移，需自行重新检查并启用。CSV 不能恢复为原始记录。

SQLite 快照采用数据库在线备份，支持最大 2 GiB，适合数据量较大的完整备份。可读 JSON 备份目前上限 112 MiB、每类最多 300 万条；超限会明确拒绝，不生成不可恢复的 JSON 备份。

## 工作历史与手动记录

顶部 **工作历史** 可按日期查看工时并保存、编辑或撤销手动记录，全部保存在本机：

日历和热力图使用相同的工时色阶，显示 VPN 与手动记录去重后的合计；圆点标记有手动记录的日期。点选日期查看来源并加载已有手动记录。默认用 24 小时时间轴拖动两端，也可切换到精确时间选择；支持多段及结束于 `24:00`。每段可从中点拆分，再调整两段时间；也可与下一段合并，如果中间有间隔，会提示增加的工时并等待确认。只记得过去一天的总工时，也可使用总小时及快捷按钮。点击保存才写入；跨午夜的工作分两天录入，未保存时切日或关闭会提示。

当天详情显示 VPN、手动、睡眠和未知分段，可展开查看原始 VPN 状态。默认以已计时段作为修正的起点，调整后才能保存：在修正范围内，只有选择的时段计入工时，其余时间（包括未知时间）不计入。修正今天时，范围截止至打开当日详情时显示的时间，此后 VPN 和睡眠继续自动记录；重新打开详情可以刷新截止时间，保存的修正时段不能超出截止时间。自动采样的秒数填入编辑器时按分钟取整，保存前请核对；也可切换回补充模式。修正不删除 VPN 采样，撤销后恢复修正前的手动记录。夏令时转换日、片段过多和仅有总小时估算时不自动生成可能失真的分段，已有总时长记录继续使用总时长模式。

VPN 正在持续连接且采样状态新鲜时，这一段会以灰色只读卡片显示，悬停、键盘聚焦或点击查看说明；修正范围收缩至其起点前，保存时也会重新检查。连接结束后重新打开工作历史即可修正这段。若保护范围与已有修正冲突，页面会暂时阻止保存以保留既有记录。

- **每日总小时**：适合只记得大致时长的过去日期，标为“手动估算”；以该值替代当天 VPN 工时，不虚构具体起止时间，不与当天 VPN 数据重复相加。允许填写 0 小时修正为休息；今天须使用具体时段。
- **具体时段**：例如 `09:00-16:00,19:00-21:00`，标为“手动补录”；与已记录的 VPN 连接区间合并，重叠只算一次。允许预填今天尚未结束的时段，但只累计截至当前时间的部分；未来日期不允许补录。
- 同一天再次保存会替换该日的手动条目。撤销补录后恢复使用原始 VPN 记录，薪资和原始采样不变；日薪、周末规则与自动记录一致。完全依靠估算的日期会明确标记来源。
- 手动估算不代表实际检测结果。演示模式不读取真实补录，离线预览禁用补录功能。

## 如何计算

- 理论时薪 = 当前生效年薪 ÷（本年理论工作日数 × 每日理论工时）。默认周一至周五、每天 **8 小时**；暂不单独扣除节假日。理论工时仅是基准，不限制 VPN 工时发生的时段；夏令时不会改变这个固定小时基准。
- 工作日固定日薪 = 当天生效年薪 ÷ 当年理论工作日数。一个日期有正时长已知区间或手动总时长，就算有记录日；工作日分配一整日日薪，即使只有晚间记录或已知断开记录。完全未知且无补录的日期不分配收入；单个采样点本身不构成有记录日。
- 每日实际时薪 = 当日固定日薪 ÷ 当天全部工作小时（VPN 与手动补录去重后的结果）；若有工时但不足 1 小时，单日时薪按 1 小时估算，真实工时保持不变。多天实际时薪 = 有记录工作日的日薪合计 ÷ 全部实际工时，**不平均每日时薪，也不对工时取整**。热力图可点选日期查看当天工时、数据来源、分配收入与实际时薪。
- 选择「今天」「本周」「本月」时，实际时薪还会与上一理论工作日、上一自然周、上一自然月的完整周期分别对比；当前周期仅算截至现在的数据，双方进度不同。上一周期无记录、无工时、缺少薪资或时薪为 0 时，不计算百分比；其他时间范围暂不显示此项对比。
- 周末等非理论工作日不额外分配固定收入，连接工时仍累计，因此周末加班会拉低整周实际时薪。零工时或相关工作日缺少薪资时显示 `—`；只有周末工作记录且无工作日收入时，实际时薪为 0。
- 今天和未完整采集的日期仍按整日日薪估算，工时增加后时薪会变化；缺失工时可能使估算偏高。页面显示有记录日期数与记录完整性，不再以排班覆盖率限制计算。时间范围边界触及的日期若有正时长已知区间，也按整日日薪计算。
- 未知日期灰色斜纹；有记录的工作时长越长，红色越深；部分覆盖有提示，未来不计入。
- 热力图默认显示今天前后各三个日历月，可跨年；未来日期标为尚未发生，不虚构工时。可切换为今年全年，也可点击“定位最近记录”；自动刷新和切换统计周期会保留手动浏览位置。
- 每日趋势随所选时间范围变化，两条折线分别显示工时与实际时薪，共用日期范围但各自标注单位。缺少记录的日期断线，已记录的零工时为 0，无法计算的时薪留空；今天仅显示截至当前的记录。点选日期可查看数值及手动补录、睡眠估算等来源；“过去一年”包含跨年日期，独立于仅显示今年的全年热力图。
- 趋势图默认“聚焦变化”：纵轴根据有效记录留出适量空间，并明确提示非零起点；工时至少保留约两小时时间跨度，时薪保留合理跨度，避免把极小变化夸大。也可切换“从零开始”对照绝对大小。
- 最后一个采样点不向未来外推；相邻观测超过 45 秒的间隔默认未知。明确记录的系统睡眠区间按“睡眠期间暂停计时”开关处理；未确认的缺口、程序停止或客户端无法读取不会无限延长工作时间。普通 VPN 采样存在约 15 秒边界误差。
- “今年”即 YTD；“过去一年”为过去 365×24 小时。季度/半年按当前自然季度/半年的起点至现在。
- 第一版明确不做手机采集或手机导入。离线或无需 VPN 的工作不会自动采集，可以通过手动补录计入；心理余波不自动判断。

## 验证

```sh
python3 -m unittest discover -s tests -v
node --check static/app.js
node --test tests/*.cjs
```

自动测试使用临时目录与虚构 VPN 检测器，不访问实际公司 VPN。覆盖脚本状态协议、非零退出码、超时、无效输出、路径配置、只读检查无写入，以及时薪分摊、DST、缺口、发布队列、单实例、演示隔离、日志筛选和访问控制。自动测试不会替你断开或重连 VPN。

## 文件

后续菜单栏 Mac app 的准备范围见 [MAC_APP_PLAN.md](../MAC_APP_PLAN.md)。当前仍使用脚本和浏览器，没有安装包；登录启动项为可选设置。

- `app.py`：本机服务、后台采样、定时发布和访问控制。
- `vpn.py`：只读状态适配；不执行连接、断开或修改 VPN 配置。
- `power.py`：通过 macOS IOKit 监听系统睡眠与唤醒，不修改系统电源设置。
- `screen_monitor.py` / `screen_alerts.py`：读取显示器休眠状态并生成本机待确认提醒，不更改工时。
- `store.py`：本机记录、设置和发布水位。
- `core.py`：时薪与覆盖计算。
- `static/`：完全本地的页面资源。
- `launcher.py`：后台启动、停止与打开本机入口。
- `autostart.py`：用户级 macOS 登录启动项的配置和状态检查。
- `instance.py`：按数据目录隔离的进程锁，避免重复采集与凭据覆盖。
- `view-logs.command`：查看默认数据目录的实时状态日志。
- `tests/`：仅用虚构数据的自动验证。
